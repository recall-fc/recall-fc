# Recall FC

> 记住足球，也重新认识足球。

Recall FC（足一把）是一款关于球员、俱乐部与足球记忆的猜谜游戏。你可以在网页直接游玩，也可以安装 Android App 随时开球。

## 游戏模式

- **今日一把**：每天一名神秘球员，八次机会，根据俱乐部、联赛、国家、年龄、位置和荣誉逐步锁定答案。
- **无限练习**：从完整题库反复挑战，找回你的足球记忆。
- **实时对战**：与其他玩家在线匹配，在相同题目中比速度、比判断。
